问题与建议请提到 [GitHub Issues](https://github.com/qingjian-team/qingjian/issues/new/choose)，按表单填写即可；表单会要求下面这些材料。
也可以加 QQ 群 [902314603](https://qm.qq.com/q/jBvn2gGTxm)（青简输入法用户内测体验交流群）直接交流。

## 反馈时请提供

1. 「偏好设置 → 关于 → 复制诊断信息」：版本、系统、加载的数据、配置原文、日志目录，写入剪贴板。API 密钥会被抹去。
2. 当天的运行日志：
   「关于 → 打开日志目录」里「~/Library/Logs/Qingjian/」下的「qingjian.log.日期」。
3. 出现问题时所在的应用、输入的内容、预期结果与实际结果。

可复现时，先打开「高级 → 详细日志」再复现一次，日志中即有逐键记录；排查完成后请关闭。

## 常见情况

- **安装后输入法列表中没有青简**：到「系统设置 → 键盘 → 输入法 → 编辑 → +」在简体中文下添加，仍没有则注销后重新登录。仍然没有，请[提交 issue](https://github.com/qingjian-team/qingjian/issues/new/choose)并附系统版本与安装方式。
- **候选窗口遮挡了终端 / 编辑器自身的补全**：英文模式在这些应用中缺省不给候选；被遮挡的是中文候选时，切换到英文模式即可。
- **登录后当前输入法不是青简**：已知问题，手动切换一次即可，待签名版解决。
- **配置文件改错**：输入法菜单会增加一条灰色的错误说明，此时沿用上一份可用的配置；按说明改回并保存即可。
- **某个应用中表现异常**（拼音渲染异常、按键被吞、无法读取选区）：请将应用名称与现象反馈给作者；可先在「候选窗口」页更换拼音显示位置作为临时处理。
